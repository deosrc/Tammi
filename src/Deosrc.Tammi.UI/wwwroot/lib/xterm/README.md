# xterm.js

The terminal emulator used by the `Terminal` component, copied unchanged from these npm packages:

| File | Package |
|------|---------|
| `xterm.mjs`, `xterm.css` | [`@xterm/xterm`](https://www.npmjs.com/package/@xterm/xterm) 6.0.0 (`lib/xterm.mjs`, `css/xterm.css`) |
| `addon-fit.mjs` | [`@xterm/addon-fit`](https://www.npmjs.com/package/@xterm/addon-fit) 0.11.0 (`lib/addon-fit.mjs`) |
| `addon-unicode11.mjs` | [`@xterm/addon-unicode11`](https://www.npmjs.com/package/@xterm/addon-unicode11) 0.9.0 (`lib/addon-unicode11.mjs`) |
| `addon-web-links.mjs` | [`@xterm/addon-web-links`](https://www.npmjs.com/package/@xterm/addon-web-links) 0.12.0 (`lib/addon-web-links.mjs`) |

They're the packages' ES module builds. The source maps are left out to keep the repository small.

All four are MIT licensed by the xterm.js authors (see `LICENSE`). To update them, download the new versions from
npm, copy the same files and update this table.
